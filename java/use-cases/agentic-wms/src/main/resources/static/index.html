What this is

A simple Warehouse Management System: goods come in, goods go out, and stock gets replenished. The twist is the last part — nobody asks for the replenishment. When an outbound invoice is executed, an AI agent wakes up on its own, looks at the stock, reads the rules agreed with the depositor and decides whether to reorder.
