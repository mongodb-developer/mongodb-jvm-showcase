# Automated Embedding

Semantic search over articles with **MongoDB Vector Search + Automated Embedding**.

Atlas generates the embeddings server side, so this application never calls an embedding provider —
it indexes text and queries with text.

Read more: [Automated Embedding Overview](https://www.mongodb.com/docs/vector-search/crud-embeddings/automated-embedding/?utm_campaign=devrel&utm_source=github&utm_medium=cta&utm_content=automated-embeddings&utm_term=ricardo.mello) 

## Stack

| | |
| --- | --- |
| Java | 21 |
| Spring Boot | 4.1.0 (Web MVC) |
| MongoDB Java Driver | 5.9.0 (sync, no Spring Data) |
| MongoDB | Atlas with Vector Search |
| Embedding model | `voyage-4`, generated by Atlas via `autoEmbedField` |

## Flow

```
startup ──> VectorIndexInit  creates the collection + vector index, waits until queryable
       ──> DataInit          inserts the articles (Atlas embeds 'content' automatically)

GET /articles/search?q=...  ──> $vectorSearch with a text query ──> ranked articles + score
```

Everything is automatic on startup:

- **Index creation** — `VectorIndexInit` builds a `vectorSearch` index with `autoEmbedField("content")`
  and blocks until it is queryable, so the first search never hits a half-built index.
- **Ingestion** — `DataInit` inserts the dataset only if the collection is empty. Embeddings are
  produced by Atlas on insert; nothing is computed in the application.

Both are `ApplicationRunner`s ordered with `@Order`, so the index always exists before the data.

## How to run

Export your Atlas connection string:

```bash
export MONGODB_URI="mongodb+srv://<user>:<password>@<cluster>.mongodb.net/"
```

Run it (Maven is not required, the project ships the wrapper):

```bash
./mvnw spring-boot:run
```

On Windows, use `mvnw.cmd spring-boot:run`.

## Searching

Ready-to-run requests are in [`src/main/resources/http/request.http`](src/main/resources/http/request.http).

```bash
curl --get 'http://localhost:8080/articles/search' \
  --data-urlencode 'q=How to organize a Java application in modules' \
  --data-urlencode 'limit=1'
```

```json
[
  {
    "title": "Clean and Modular Java: A Hexagonal Architecture Approach",
    "content": "An approach to organizing Java applications in a modular way using hexagonal architecture concepts",
    "url": "https://foojay.io/today/clean-and-modular-java-a-hexagonal-architecture-approach/",
    "score": 0.87
  }
]
```

The query has almost no words in common with the stored text — the match comes from meaning, not keywords.

## Configuration

Defaults live in `src/main/resources/application.properties` under `article.vector-index.*`
(database, collection, index name, embedded field, model, `numCandidates`, startup timeout).
